Poligonul

Un poligon este o linie poligonală închisă ale cărei laturi nu au alte puncte comune decât vârfurile consecutive.
Pentagonul ABCDE are:
  • 5 vârfuri (A, B, C, D, E);
  • 5 laturi ([AB], [BC], …);
  • 5 unghiuri.
Diagonala unește două vârfuri neconsecutive. În ABCDE, [AC] este diagonală, iar [AB] este latură.

Poligon convex și concav

Un poligon este convex dacă segmentul determinat de oricare două puncte din interiorul său se păstrează în interiorul poligonului; în caz contrar este concav.

Formule importante

Suma unghiurilor unui poligon convex cu n laturi:
S = (n − 2) · 180°
Exemplu: hexagon: S = (6 − 2) · 180° = 720°. Poligon regulat = toate laturile congruente și toate unghiurile congruente (triunghiul echilateral, pătratul). Unghiul unui poligon regulat:
α = (n − 2) · 180° / n
Exemplu: hexagon regulat: α = 720° / 6 = 120°. Dacă un poligon convex are n laturi, atunci:
  • dintr-un vârf pot fi construite n − 3 diagonale;
  • el are n(n − 3)/2 diagonale;
  • suma unghiurilor este 180°(n − 2).
Pentru patrulater convex: suma unghiurilor = 360°.
